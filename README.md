# W02 · Git practice

Practice repository for TA session 2 of *AI Fluency and Agentic Methods for Engineers*
(00560413, Technion, Winter 2026–27).

It has two branches:

- `main`: the finished version.
- `develop`: where new work happens first. It has one extra file, `develop.md`.

## What you do with it

1. **Fork** it. On the fork page, untick **Copy the `main` branch only**, so your copy gets both branches.
2. **Clone** your fork in VS Code.
3. **Switch** to `develop`, add `about-me.md`, commit, and push.
4. **Merge** `develop` into `main` in VS Code, and push `main`.
5. Change `about-me.md` on `develop` again, and merge it through a **pull request** inside your own fork.

This is a practice repository. Your project (M1) lives in its own repository.
